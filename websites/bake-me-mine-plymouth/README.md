# Bake me mine — independent website concept

A new, unsolicited concept for Bake me mine in Plymouth, Minnesota, USA. This is not the business's official website and is not endorsed by the bakery.

- Live: https://amalraj020-a11y.github.io/10am-office-work/websites/bake-me-mine-plymouth/
- Office model: `openai/gpt-6-astra`, approved ChatGPT OAuth route, verified during this run.
- Source template: [Creative on ThemeWagon](https://themewagon.com/themes/free-bootstrap-5-html-5-personal-portfolio-website-template-creative/), free Bootstrap 5 template.
- Upstream: https://github.com/StartBootstrap/startbootstrap-creative
- Pinned upstream commit: `b1762d8c690a2379c078c776dc0830bdd81c6f55`.
- MIT license: original notice preserved in LICENSE and CSS/JS headers. MIT does not require visible attribution. Bootstrap 5.2.3 license is preserved separately.
- Adaptation retains Creative's navbar, masthead, responsive Bootstrap grid, section structure, compiled theme stylesheet, scrollspy and navigation behavior. Replaced all template copy; removed portfolio demo photos, fake form, stock business identity and lightbox dependencies. Added bakery-specific styling and original decorative SVG artwork by MultiMax. Illustration is explicitly not a product photograph.
- All assets are local. No paid services, analytics, forms, payments, ordering backend, external font requests or third-party image hotlinks.
